```python
class Solution(object):
    def reverseList(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        if head is None:
            return head
        stack = []
        while True:
            stack.append(head)
            if head.next is None:
                break
            head = head.next
        dummy = ListNode(next=head)
        for i in range(-1, -1*len(stack)-1, -1):
            head.next = stack[i]
            head = head.next
        head.next = None
        return dummy.next
```
時間計算量：O(n), n = len(linked list)<br>
実行時間：(5 * 10^3) / 10^6 = 5 * 10^{-3} s<br>
空間計算量：O(n)<br>
空間計算量がO(１)くらいの解法がありそうだとぼんやり思う。
```python
class Solution(object):
    def reverseList(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        if not head or head.next is None:
            return head
        
        prev = None
        while True:
            if head.next is None:
                head.next = prev
                return head
            prevprev = prev
            prev = head
            head = head.next
            prev.next = prevprev
```
