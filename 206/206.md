```python
class Solution(object):
    def reverseList(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        if head is None:
            return head
        stack = []
        while True:
            stack.append(head)
            if head.next is None:
                break
            head = head.next
        dummy = ListNode(next=head)
        for i in range(-1, -1*len(stack)-1, -1):
            head.next = stack[i]
            head = head.next
        head.next = None
        return dummy.next
```
時間計算量：O(n), n = len(linked list)<br>
実行時間：(5 * 10^3) / 10^6 = 5 * 10^{-3} s<br>
空間計算量：O(n)<br>
空間計算量がO(１)くらいの解法がありそうだとぼんやり思う。
```python
class Solution(object):
    def reverseList(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        if not head or head.next is None:
            return head
        
        prev = None
        while True:
            if head.next is None:
                head.next = prev
                return head
            prevprev = prev
            prev = head
            head = head.next
            prev.next = prevprev
        return head
```

この問題が再帰で解きうるという点が初めまるで理解できず苦労したが、どうやら以下のような発想っぽい。<br>
```
`1 -> 2 -> 3 -> 4 -> 5`を逆順にするというのは、
     `2 -> 3 -> 4 -> 5`を逆順にする、
          `3 -> 4 -> 5`を逆順にする、
               `4 -> 5`を逆順にする
という問題を部分的に含む。
加えて、これらの問題の間には包含関係がある。
つまり、
`1 -> 2 -> 3 -> 4 -> 5`を逆順にする
\sup `2 -> 3 -> 4 -> 5`を逆順にする
     \sup `3 -> 4 -> 5`を逆順にする
          \sup `4 -> 5`を逆順にする
という問題の減少列がある。
よってこの問題は減少列を下って最も簡単な逆順処理が行われた後、今度は逆に、linkを増やしながら「上って」行けばよい。
言い換えると再帰的に問題が解ける。
```

```python
class Solution(object):
    def reverseList(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        if head is None or head.next is None:
            return head
        new_head = self.reverseList(head.next)
        head.next.next = head
        head.next = None
        return new_head
```

```python
class Solution(object):
    def reverseList(self, head):
        """
        :type head: Optional[ListNode]
        :rtype: Optional[ListNode]
        """
        if head is None or head.next is None:
            return head
        node = None
        while head.next is not None:
            prev = node
            node = head
            head = head.next
            node.next = prev
        head.next = node
        return head
```
