### Step 1
5分で書ききれなかった。
方針としてはstrをsplitしていってaliasをよけつつcanonicalな名前を辞書とかに登録することを考えた。
回数の情報はいらないのでsetにaddするのでもいいかも？
```python
class Solution:
    def numUniqueEmails(self, emails: List[str]) -> int:
        canonical_addresses = set()
        for addr in emails:
            local, domain = addr.rsplit('@', maxsplit=1)
            # identify canonical
            t = []
            for c in local:
                if c == '.':
                    continue
                if c == '+':
                    break
                t.append(c)
            canon = ''.join(t) + '@' + domain
            # enroll
            canonical_addresses.add(canon)
        
        return len(canonical_addresses)
```
