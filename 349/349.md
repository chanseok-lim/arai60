```python
def slice_around_target(target: int, nums: List[int], slice_size: int = 32) -> List[int]:
    left = 0
    right = len(nums)//2
    while True:
        if left - right <= slice_size:
            return nums[left:right]
        else:
            if n <= nums[right]:
                left, right = left, right//2
            else:
                left, right = right, len(nums)

intersection = []

assert len(nums1) > len(nums2), f'len(nums1) must be larger than len(nums2)'
for n in nums2:
    run = slice_around_target(n, nums1)
    if n in run and n not in intersection:
        intersection.append(n)
```
slice_around_targetの計算量がO(logn)
全体の計算量はO(mlogn), n, m = len(nums1), len(nums2)
nums2が小さいなら、setにキャストしてもいいかも。
