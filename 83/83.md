*Accepted*
```
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        node = head
        while node is not None:
            forward = node.next
            while forward is not None:
                if node.val != forward.val:
                    node.next = forward
                    break
                forward = forward.next
            if forward is None:
                node.next = None
            node = node.next
        
        return head
```
時間計算量: O(n), n = the number of nodes in the list <br>
実行時間: 3 * 10^2 / 10^{-6} = 3 * 10^{-4} s
空間計算量: O(1)
