```python
class Solution:
    def filter_first_unique(
        self, char_to_indeces: Dict[str, List[int]]
    ) -> (str, int):
        unique_chars = []
        for c, inds in char_to_indeces.items():
            if len(inds) == 1:
                unique_chars.append((c, *inds))
        unique_chars = sorted(unique_chars, key=lambda x: x[1])

        if not unique_chars:
            return (None, -1)
        else:
            return unique_chars[0]

    def firstUniqChar(self, s: str) -> int:
        char_to_indeces = defaultdict(list)
        for i, c in enumerate(s):
            char_to_indeces[c].append(i)
        _, i = self.filter_first_unique(char_to_indeces)
        
        return i
```
時間計算量：<br>
char_to_indecesの作成 + unique_charsの作成 + sorted<br>
= n + n + mlogm = 2n + mlogm = (2+rlogr+rlogn)n, 0 < r < 1<br>
O(nlogn)<br>
実行時間：10^5 * 5 / 10^6 = 5 * 10^{-1}<br>
lowercase letterに対するチェック忘れてた。
