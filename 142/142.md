出題意図を図りかねる。
```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        visited = set()
        node = head
        while node is not None:
            if node in visited:
                return node
            visited.add(node)
            node = node.next

        return None
```
時間計算量: O(n), n = length of cycle<br>
空間計算料: O(n)<br><br>

あ、これ、「ウサギとカメ」で解こうとすると面倒だな？<br>
$\because$ うさぎとかめはcycleの始まりで会うとは限らない。<br>

「ウサギとカメ」でも解けるらしい。理屈を考えてみる。<br>
まずは普通の「ウサギとカメ」；
```
サイクルまでのノードの長さをT、サイクルの長さをCとする。
ウサギとカメはどちらもノードからスタートする一方、ウサギはカメのs (>2) 倍のステップで進む。
N (>T) ステップ後にウサギとカメが衝突するならば、
T + kC + r = sN かつ T + r = N<br>
である。よって
(s - 1)N = kC
を満たす正の整数の組み (N, k) が存在するとき、ウサギとカメは衝突する。
特にs = 2 の時、N = kCである。
```
今回はサイクルのスタート地点、つまり、TもしくはN - rを求めたい。<br>
Nは普通の「ウサギとカメ」を解けば求まる。特にN = Cである（なぜなら最小のNがもとまっているので）。<br>
$\rightarrow$ カメにサイクルを進ませれば良い。<br>
サイクルの残りはM = C - rより、M = C - r = N - r = Tであり、<br>
サイクルを継続して進むカメとスタート地点から進むカメを用意して、衝突するところがサイクルの始まり。<br>
```
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, x):
#         self.val = x
#         self.next = None

class Solution:
    def detectCycle(self, head: Optional[ListNode]) -> Optional[ListNode]:
        fast = head
        slow = head
        collision = False
        while (fast is not None) and (fast.next is not None):
            fast = fast.next.next
            slow = slow.next
            if fast is slow:
                collision = True
                break

        if collision:
            slow2 = head
            while slow is not slow2:
                slow = slow.next
                slow2 = slow2.next
            return slow
        
        return None
```
